# 还在手动数 Markdown 的 `#`？这款开源 MD 查看器，把预览、编辑、AI 排版和 HTML 设计器一次装齐！

如果你经常写 Markdown，一定遇到过这些场景：想快速预览文档，却要在编辑器和浏览器之间来回切换；想修改标题层级，只能手动增删 `#`；想整理一篇长文，还要额外配置排版、代码高亮和 Mermaid 图表。

现在，这些事情可以交给一款轻量的桌面工具完成。

MD查看器是一款基于 Wails、Go 和 Vue 3 构建的开源 Markdown、纯文本、轻量 HTML 与 PPT 设计整理工具。它把预览、所见即所得编辑、源码分栏、文件树、大纲导航、工作区搜索、AI 排版、HTML 设计器和 PPT 生成编辑放进了一个简洁的桌面应用里。

![MD查看器 GitHub 配图](https://raw.githubusercontent.com/qizhenghai2020/mdview/master/docs/screenshots/preview.png)

## 为什么值得试试？

- **三种工作模式**：预览、编辑、分栏随时切换，既能专注阅读，也能边看效果边改源码。
- **右键编辑增强**：右键即可插入标题、引用、任务清单、表格、图片、代码块和 Mermaid 图表。
- **标题大纲快捷调整**：右击 `#` 标题，使用“升级”“降级”或直接选择一级到六级标题，不必再手动数井号。
- **多文件与文件夹工作区**：打开一组 Markdown、TXT、日志、配置或代码文件，用文件树快速浏览和切换。
- **工作区搜索与定位**：按关键词搜索当前文件和工作区内容，按文件分组展示结果，点击即可跳转定位。
- **Markdown 内容增强**：支持代码高亮、Mermaid 图表、相对路径图片、任务清单和表格展示。
- **AI 排版与内容辅助**：支持多供应商、多模型配置，可对 Markdown 和 HTML 进行 AI 排版，部分右键插入项也支持 AI 生成。
- **AI PPT 生成与编辑**：将文档生成可编辑 PPT，支持自定义页数、参考图片、分批生成、进度展示和生成后继续设计。
- **HTML 设计器与导出**：可视化调整 HTML 页面结构，执行 AI 优化，并导出设计结果。
- **主题与样式系统**：支持内置主题、AI 智能主题、外置字体和细粒度样式配置。
- **外部文件同步与冲突保护**：自动感知磁盘文件变化，减少本地编辑与外部修改之间的冲突风险。
