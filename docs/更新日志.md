# 更新日志

## 2026-07-22（v1.0.3）

- 编辑模式与分栏编辑新增统一右键增强菜单，可快速插入标题、引用、任务清单、表格、图片、代码块和 Mermaid 内容，并为部分块级内容提供 AI 生成入口。
- 针对 `#` 标题新增“标题大纲”右键操作，可通过 `升级 / 降级 -> 一级标题到六级标题` 直接把当前标题调整到目标层级，减少手动修改井号数量的成本。
- 更新 `README` 与项目说明文档，补齐当前版本的工作模式、右键编辑、AI 辅助和桌面工作流介绍，避免文档描述与实际功能脱节。

## 2026-07-19（v1.0.2）

- 常规配置新增左侧导航默认页签设置，支持按使用习惯指定启动后的默认展示内容。
- 新增多供应商、多模型管理能力，模型配置更加灵活，适配更多使用场景。
- 优化 Markdown 查看器的 AI 排版效果，并新增多种常用生成格式推荐，提升内容整理效率。
- 新增 HTML 设计器与 HTML 导出功能，同时支持对 HTML 内容进行 AI 排版处理。
- AI 功能新增默认供应商与默认模型配置，减少重复选择，提升日常使用便捷性。
- 新增外置字体加载功能，将字体文件放入 exe 同目录的 `fonts` 文件夹后即可直接使用。
- 新增主题圆角开关、预览模式表头对齐方式、表格宽度铺满等显示配置，界面控制更细致。

## 2026-07-16（v1.0.1）

- 优化顶部工具栏与模式切换体验，统一按钮展示逻辑，增强常用操作在不同窗口宽度下的可读性与一致性。
- 优化智能主题管理，新增内置主题与 AI 主题统一列表、生成主题置顶展示、主题列表区扩展以及主题切换结果持久化。
- 修复 `Ctrl + 鼠标滚轮` 整体界面缩放后的布局异常问题，并修复左侧导航开关状态在重启软件后未正确保持的问题。
- 补充项目开源协议，新增 `Apache License 2.0` 许可证文件，并在 `README` 中同步标注协议说明。

## 2026-07-16（v1.0.0）

- 新增 `预览 / 编辑 / 分栏` 三种工作模式，支持所见即所得编辑、Markdown 源码同步、Mermaid 图表和可拖动分栏。
- 新增多文件与文件夹工作区，可打开、拖入和切换多层目录中的文件，并通过左侧文件树与文档大纲统一导航。
- 扩展常见文本文件与多种中文编码支持，除 Markdown 外也可安全查看和编辑 TXT、日志、配置及代码文件。
- 新增外部文件自动同步与双向编辑冲突保护，可在本地编辑和磁盘变更冲突时选择保留的版本。
- 新增 AI AI排版与模型管理，支持模型测试、自定义请求配置、排版要求输入以及应用前的双栏预览确认。
- 新增 AI 智能主题生成，可在样式面板中生成、切换和删除个性化 UI 主题，并自动应用到当前界面。
- 新增独立样式配置和应用设置，可维护主题、排版、元素覆盖、任务清单样式及常用界面状态的保存策略。
- 新增整体界面浏览器缩放控制，支持 `Ctrl + 鼠标滚轮` 缩放，并可在常规设置中一键还原到 100%。
- 优化字体体系，保留 Windows 常用字体并内置阿里巴巴普惠体、思源黑体风格和思源宋体风格，同时显著缩减程序体积。
- 重构 Windows 一体化窗口与主题界面，完善标题栏、导航、缩放和亮色、暗色、雅致主题下的整体体验。
